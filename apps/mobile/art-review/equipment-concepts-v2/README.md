# T1–T5 two-path equipment concepts

These nine review boards establish the visual direction before any runtime
atlas is made. Each board uses the same layout:

- top row: Foundation, T1 through T5 from left to right;
- bottom row: Alternate, T1 through T5 from left to right.

They are concept references only. They are deliberately not bound in the app,
and must be translated into the compact transparent 5 × 2 runtime atlas only
after review against `../t1-t9-equipment-icons-v1/ART_DIRECTION.md`.
