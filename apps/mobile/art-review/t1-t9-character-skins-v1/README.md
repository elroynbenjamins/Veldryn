# Ironwarden T1 front-view skin candidates

These six 1024 x 1536 front portraits were accepted for the first
three T1 Ironwarden sets. The male and female base mannequins provide the
identity, proportions, neutral pose, and dark vignette. The accepted `-v2`
[equipment atlases](../t1-t9-equipment-icons-v1/README.md) and approved
[T1 concept](../t1-t9-visual-previews/ironwarden-t1-three-paths-concept-v2.png)
provide the outfit and shield designs.

| Set | Male | Female |
| --- | --- | --- |
| `T1_001` Oathbound Rampart | [front](T1_001-oathbound-rampart/male-front.png) | [front](T1_001-oathbound-rampart/female-front.png) |
| `T1_002` Chainmarshal Plate | [front](T1_002-chainmarshal-plate/male-front.png) | [front](T1_002-chainmarshal-plate/female-front.png) |
| `T1_003` Emberwatch Reprisal | [front](T1_003-emberwatch-reprisal/male-front.png) | [front](T1_003-emberwatch-reprisal/female-front.png) |

The portraits here retain their original vignette for art review. Transparent
RGBA cutouts are bound in `../../assets/character-skins-t1-ironwarden/` and
selected in-game after a character collects all ten pieces of a set. New
skins are front-only; back-view requests use the front artwork.
