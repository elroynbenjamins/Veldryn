## Quest engine and journal
Define stable versioned IDs, scopes (character/account), explicit prerequisites (all/any, no cycles), multi-stage objectives with typed sources (settled kills, craft actions, owned/equipped readiness, verified boss, scouting report/discovery, level, travel/access, deterministic lore). Distinguish lifetime fact goals vs since-activation counters; completed facts can be retroactive where authored, counters start at activation and dedup trusted receipts. Avoid forced item consumption unless explicit transaction with quote. Offline settlement is canonical, not client time. Keep current/claimable/claimed/locked status, show reasons and pin one quest per character. Journal reads evidence, cannot mutate gameplay except separately authorized commands. Server claim atomic/idempotent with stable quest/reward version and account-once cosmetic IDs; no double payout after migration or retry.

Four compact tabs: Story (current quest, book/act list, chronicle), Quests (side, profession, contracts), Challenges (daily/weekly/monthly), Records (achievement/title/mastery/personal records; existing Codex links). Keep guild/party/dungeon objectives in their own systems with deep links. Migrate old navigation entries and selected tab without duplicate screens; small-phone, large font, accessible labels, eight languages. Account-wide lore with character-specific campaign progress; shorten repeat-character dialogue but retain boss checks. Account-wide optional profession/scouting achievements must not reset with character switches; ordinary profession quests character-specific unless explicitly account-scoped.
