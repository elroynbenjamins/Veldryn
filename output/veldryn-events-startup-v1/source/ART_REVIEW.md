# Art review

Generated with the built-in ImageGen tool, one asset per request. Exact initial prompts are in `jobs.json`; accepted source paths and final prompts are in `results.json`; the complete refinement chain is in `refinement-history.json`.

References inspected: existing Wheat Crown profile border, Harvestwake and Aurora Citadel profile backgrounds, Winter's Bell concept overview and Anniversary of Veldryn concept overview. The event concept README and runtime Harvestwake definition established names and visual identity.

The anniversary art was refined from a four-point crystal to the accepted eight-point gold sunburst with a round blue stone. An intermediate revision returned painted backgrounds; ImageGen removed them, and final source-alpha checks passed. Earlier source copies can remain for provenance; use only the manifest's runtime paths in the app.

Final review inspected the three 360×780 startup assemblies, matching event overlays on existing profile backgrounds, standalone frames and badges. The generated scenes reserve sky for separate branding and dark foreground for loading information. Existing profile art and rewards were preserved.
