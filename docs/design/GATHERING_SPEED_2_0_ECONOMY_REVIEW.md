## Policy
Retain the user-approved 10% base innate per piece and 10% chest chance. Gear rating soft curve proposed: first +100% full, next +100% at 75%, above +200% at 50%; existing tools and established buffs preserved. At Q50, ten common pieces plus set speed give +103.1275% effective rate, versus +202.085% for ten Q100 mythic pieces plus set speed, excluding affixes. A full common set is already a substantial gain. Do not blanket-increase recipe costs for all players to compensate for scarce chest drops. First measure adoption, distribution of set sizes, daily supply, crafting sinks and price movement. Avoid assuming a full Mythic set is common.
