# VELDRYN Play feature graphic · idle MMO RPG direction

This concept foregrounds VELDRYN's three pillars: an active idle hunt, current selectable profile portraits, and a four-role co-op dungeon party. It uses only existing game artwork: the Ironwood Forest region, the Ironwood Wolf, current profile portraits and class emblems, and the real wordmark. The portraits are cosmetics rather than representations of equipped armor. The two compact status panels are marketing representations of implemented activity and ready-check flows; they are not screenshots or live account data.

- Google Play feature graphic: `exports/feature-graphic-1024x500.png`
- Larger promotional version: `exports/promotional-banner-2048x1000.png`

Both exports are opaque 24-bit RGB PNGs. Google Play's [feature graphic requirement](https://support.google.com/googleplay/android-developer/answer/9866151?hl=en) is 1024 × 500 in JPEG or 24-bit PNG. No file in this pack has been uploaded.

Rebuild from the repository root with `node marketing/play-store-v5/compose.cjs`. This version is deterministically composed from actual in-game assets, with no generated-image prompt or model output.
