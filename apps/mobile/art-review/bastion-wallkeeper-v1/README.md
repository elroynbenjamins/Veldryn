# Wallkeeper Initiate concept pass

Female and male front/back Wallkeeper Initiate concepts. The set uses fitted charcoal plate, gold trim, blue tabard and a tower shield. Face and hairstyle remain visible in each front view; helmet is off.

`female-front-hood-off-alpha.png`, `male-front-hood-off-alpha.png`, and `male-back-hood-off-alpha.png` are background-cleaned candidates. The male-back version had its low-alpha dark halo removed while preserving the opaque armor sprite.

All files are concept masters, not live game assets.
