# Veldryn — Companion Training and Companion Mastery (v1)
Status: **Implemented in GitHub feature branch, pending server deployment and a new Android build** (2026-11-10)

## Distinct progression systems
- **Companion Training Ground**: Sanctuary facility levels 0–3; each claim grants 0/24/52/84 XP per elapsed day to eligible idle companions, maximum seven days accumulated. It is **not** a skill and does not directly modify combat stats.
- **Companion Mastery**: Account-wide, persistently stored earned XP, derived skill level 1–100. Present in Skills > Related Progression with earned XP, live buffs and source explanations. This does not depend on the currently selected character.
- **Individual companion progression**: Level, Bond, Ascension, rarity and technique keep their existing balancing. Mastery is applied after the normal scaling, never folded into persistent per-companion stats.

## Trusted XP sources
- Claiming a finished Expedition: XP from the duration of that server-created assignment and its achieved reward grade. The existing claimed status prevents reclaims.
- Clearing a Trial floor: XP based on cleared floor, with additional first-clear/boss awards. Failed or abandoned runs award no Mastery XP. Server floor progression prevents repeat claims.
- Claiming Training Ground days: XP based on full elapsed days (up to seven) and up to three eligible companions; same-day retry awards nothing.
- No standalone “grant Mastery XP” client command exists. XP is only awarded inside existing validated gameplay transactions.

## Level and power balance
- Skill starts at level 1 and caps at level 100.
- XP to advance from level `n`: `floor(120 + 16*n + 1.75*n^1.45)`. The account's stored XP is capped at the cumulative level-100 threshold and normalized on save load. No retroactive XP was minted.
- Progress factor: `(level-1)/99`. Applied incrementally:
  - Level 100: **+5% companion HP, Attack and Defense** in the canonical companion-only battle builder (Trial combat) and the companion power projection (Trials/Expeditions), no change to crit chance, haste or cooldown speed.
  - Level 100: **+10% individual companion XP** from supported settled gameplay XP sources.
  - Level 100: **+5% effectiveness of the existing equipped-companion assist** in character combat. This boosts the existing companion contribution by 5%, *not* the player's entire Attack/Defense by five percentage points.
- Companion stat bonus is derived from trusted account XP and passed through a **runtime-only** field on companion snapshots; the field is stripped on state persistence. No repeat stacking after successive combat or claim calls.
- Existing Sanctuary facility upgrades and companion rarities remain unaffected.

## Deployment and future work
- This change requires regenerated server `gameplay` and `coop` Edge bundles; both are generated by the canonical `pnpm --dir backend build:online` command. GitHub CI must pass generated-bundle parity.
- Merging GitHub code **does not deploy** the updated server functions or supply a new Android build; do not promise players the buff until both are deployed.
- Later balancing proposals: first/seasonal XP achievements, limited special-boss Mastery XP, additional milestone cosmetics at levels 25/50/75/100, and differentiated Expedition utility. Those remain **unimplemented**, not implied unlocks.
