# Beginner class sets v1

This batch contains the first craftable ten-piece equipment set and its matching
male/female front/back character skin for every playable class.

## Production prompt set

Equipment atlases used the previous class atlas for identity and the accepted
Rimewall atlas for technique. Each prompt required a 5×2 layout in this order:
helmet, chest, gloves, legs, boots, weapon, offhand, cape, amulet, ring. The art
direction required visibly low-tier repaired materials, restrained colors,
chunky hard pixels, readable silhouettes, no text, and a flat magenta key.

Character turnarounds used all four approved Aster Iron pilot-aligned views plus
the matching beginner atlas. Each prompt required a single row ordered male
front, male back, female front, female back; identical mannequin anatomy, pose,
ground line, pixel scale, and backdrop; clothing-only changes; visible wear and
repairs; and no weapons, effects, labels, smooth painting, or 3D rendering.

## Sets

- Ironwarden — Ironwarden Recruit
- Bastion — Wallkeeper Initiate
- Dreadguard — Chainwatch Novice
- Dawnkeeper — Sunlamp Acolyte
- Wayfinder — Trailbow Scout
- Ravager — Breaksteel Marauder
- Hexweaver — Runespark Adept
- Knife Dancer — Twinstep Initiate
- Stonecaller — Earthseal Disciple

`equipment-ui/` stores the transparent review atlases. `skins/` stores the
source turnarounds and the four cropped runtime portraits for each set.
