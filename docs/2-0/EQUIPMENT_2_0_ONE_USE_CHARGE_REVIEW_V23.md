## V23 phase-separated one-use charges
Extend the existing private token-gated Ravager QA adapter, retaining the four V22 source IDs/two mechanics. Add exact source candidates:
- Avalanche four-piece Follow-Through: original effective direct physical class-ability hit earns next eligible basic attack +6% damage within 6s; 16s ICD.
- Glacier Talons two-piece Talonstrike: same trigger/consumer +6% within 5s; 14s ICD.
- Rootbound Thornstrider four-piece Signature: two consecutive original effective direct class ability hits on same enemy earn next eligible direct class ability +6% within 6s; 18s ICD.

Trigger is post-HP resolution before secondary effects, consumption is before shield and HP resolution of a subsequent qualifying hit. Receipt identity tracks each engine hit's pre/post phase exactly once; no post receipt without pre receipt. Same timestamp cannot consume a newly earned charge or advance the sequence twice. This is deliberately conservative pending actual cast/action IDs; simultaneous separate actions are also excluded. Thornstrider consumes on same target as the earned streak (conservative target policy, source did not specify consumption target). A class-ability miss clears streak; changing target resets count; ordinary basic attacks do not advance or break ability streak. No charge refresh while active; exact expiry boundary, separate shared-family cooldown, no charge for fully absorbed baseline, missed, periodic, generated, true, invalid or self damage. No extra attack. Combined eligible consumption adds +12%; shared 20% same-event candidate cap includes current-hit effects. A proc may consume despite zero marginal damage if baseline already kills. No final coefficient approval or ownership of hypothetical pieces.
