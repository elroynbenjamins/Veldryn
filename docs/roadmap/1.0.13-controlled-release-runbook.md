## Abort/rollback
- Halt distribution/rollout on elevated gameplay 5xx/409, claim duplication, login lock, incorrect ownership, privacy leak or crash. Preserve old client access and prior version policy. Revert UI-only rollout before forcing updates.
- Before any live grants, restore previous Edge bundle and schema only with verified migration reversal; preserve original owners/ACLs and exact definitions. After any live grants/receipts, NEVER drop grant or undo tables or disable the grant-authority path as a shortcut. Keep entitlement-aware gameplay and receipt wrappers active; pause full-set command independently, confirm ordinary saves and existing cosmetics remain valid, and forward-fix. Revoke a specific grant only when authorized; never erase audit/receipts. If rollback requires reverting database functions, design and validate a data-preserving migration first.
- Do not use the historical test fixtures against production. Their rollback guarantees are for isolated staging only.
