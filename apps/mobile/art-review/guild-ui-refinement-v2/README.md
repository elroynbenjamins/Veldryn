# Guild UI refinement concepts

`guild-refinement-concepts.png` is a proposed three-screen layout sheet for the permanent Guild Token Shop, Guild Home and Hall. Generated with the built-in image-generation tool on 18 October 2026, using `output/event-shop-density-shell.png` and `output/guild-board-density-shell.png` as style references.

Prompt brief: preserve VELDRYN's compact dark mobile UI, detailed pixel art, board tabs, mint progress and restrained panels. Show shop Browse/Earn/Projects, category and affordability tools, inline Balance/Cost/After purchase review; task-focused Home; and progression-focused Hall. Include existing top/bottom game navigation. Avoid parchment, wood or ornamental fantasy UI.

This is a visual concept, not runtime UI or live account data. Implementation must use existing theme tokens and shipped art, including the current monster/construct Guild companions. Generated icon interpretations and selector tints are illustrative. The authoritative Fellowship Silver requirement is Guild Level 2; the mockup's Level 3 label is not a balance change. Illustrative offer counts do not replace the twelve-item server catalogue. Primary Guild navigation must preserve Chat and Manage, which can continue offscreen horizontally.
