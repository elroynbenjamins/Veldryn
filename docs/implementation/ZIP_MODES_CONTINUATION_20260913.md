# ZIP mode continuation

The library audit identified the VELDRYN Pass 7 continuation package and its predecessor Pass 7 Seasons + Weather package. The unrelated `RisingGuildmaster_Main.zip` is a separate application tree and is not merged.

This continuation adds the authored Faith, Herbalism, and Alchemy catalogs and their deterministic reservation, settlement, refund, and preparation modules under `apps/mobile/src/content` and `apps/mobile/src/core`. Existing character state, activity, reward, item, skill, and activity artwork types were extended additively so companion, social, and online systems remain intact. Herbalism nodes are now visible in the Skills screen and use the same region/activity presentation as the existing gathering professions. Alchemy recipes are included in the shared recipe catalog while timed batches use the dedicated reservation API.

The current game engine already contains Faith settlement hooks, initializes the new account skills, settles Alchemy batches, exposes a Herbalism start path, and routes `BREW_*` recipe actions into timed batch reservations. The existing Skills screen now lists Herbalism nodes and Alchemy recipes; the Character screen exposes Faith controls. Online gameplay now persists the full authoritative state JSON for these modes, and roster creation/switching is available through server-validated `roster_create` and `roster_switch` commands. Secondary online characters receive fresh server identities, and Herbalism actions are included in verified online activity validation. Migration `20261017000000_online_roster_persistence.sql` keeps the relational active-character projection synchronized during those transitions; no production migration or feature flag was enabled by this pass.

Validation: the mobile core regression suite, mobile TypeScript typecheck, backend online TypeScript typecheck, authenticated Faith/Herbalism/Alchemy/roster regression, generated edge-bundle parity checks, and `git diff --check` pass after the additive merge. The copied mode fixtures remain available under `apps/mobile/tests` for the next integration pass. The generated Supabase gameplay and co-op bundles are rebuilt from the tested online entrypoints.

Online regression now also covers the later-region sequence: authenticated travel to Sunscar, scouting and persisted encounter discovery, activity-lane stop semantics, regional Herbalism, regional Alchemy reservation/settlement, and subsequent Sunscar combat replay recovery.
