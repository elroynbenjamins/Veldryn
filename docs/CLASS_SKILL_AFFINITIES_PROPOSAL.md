# Class skill affinities — proposal, not active balance

September 24, 2026. This document does not enable XP or speed modifiers.

Recommend one modest affinity per class: +5% XP per action and +3% action speed in the same profession. All classes retain access to all professions, normal requirements and the same mastery cap. No penalties to non-affinity skills, exclusive recipes, account-wide stacking, character/combat XP bonus, or combat Haste bonus.

Shared affinities are intentional: do not force a weak thematic match solely to make every pairing unique. These mappings and numbers remain a design proposal until approved.

At baseline, 1.05 × 1.03 = 1.0815, or +8.15% XP per unit time, before other modifiers and rounding. A speed bonus means base duration / 1.03, not an additional XP multiplier. Materials, Gold, food/fuel per action and per-roll drop/quality chances remain unchanged; more actions per hour naturally consume more inputs and produce more outputs. Never increase loot quantities a second time to apply the speed bonus.

Before enabling: implement one authoritative resolver across online/offline claims, previews, processing, alchemy and forge duration paths; preserve fractional XP and activity/job snapshots; settle old character work before switching; test all nine classes, non-affinity skills, queues, active-job resume, save round-trips and displayed versus actual durations. Add to each existing bonus bucket once rather than duplicating the benefit in previews and rewards.

Presentation: one compact affinity line in class details, then an exact XP/speed breakdown on the relevant skill screen. Do not add another mandatory character-creation popup or a profession-selection step. Combat identity should remain the primary reason to choose a class.
