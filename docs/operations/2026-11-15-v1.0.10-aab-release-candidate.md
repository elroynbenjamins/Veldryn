## Required release workflow

From repo root, after integrating and resolving issues:

```sh
node tools/check-v110-aab-readiness.mjs
pnpm --dir backend install --frozen-lockfile
pnpm --dir apps/mobile install --frozen-lockfile
pnpm --dir backend build:online
node tools/verify-gameplay-edge.mjs
# Inspect and commit canonical generated gameplay/co-op Edge files when changed.
pnpm --dir apps/mobile typecheck
pnpm --dir apps/mobile test:core
pnpm --dir apps/mobile exec expo-doctor
```

Run the existing Android native bundle + Android 15 emulator smoke validation and release-specific CI on the exact final SHA. Test the live dungeon join/rejoin/boss/reward flow, run tonic/potion consumption, Forge/gear sales and gem merges, account social/party visibility, old-client version-gate behavior, and offline/online recovery on physical Android.

Once all **release gates pass**, build the **signed production AAB**, from `apps/mobile` with the correct Expo account/EAS signing credentials:

```sh
npx eas-cli build --platform android --profile production --non-interactive
```

Check the resulting build's **1.0.10/versionCode, package ID, signing and release-channel environment**, inspect the signed AAB, then upload to Google Play's intended test track. **Do not promote, increase the mandatory version above 1.0.9, or mark 1.0.10 released** until successful installation and release approval.
