# VELDRYN Play feature graphic · in-game direction

This revision is built from the game's real Ironwood Forest environment, an unmodified crop of the Combat Preview component, and the existing VELDRYN wordmark. No gameplay UI or character art was generated for the final image. The small tagline is marketing copy, outside the game crop.

- Play upload: `exports/feature-graphic-1024x500.png`
- Larger version: `exports/promotional-banner-2048x1000.png`

Both files are opaque 24-bit RGB PNGs. The [Google Play feature-graphic requirement](https://support.google.com/googleplay/android-developer/answer/9866151?hl=en) is 1024 × 500, JPEG or 24-bit PNG. No Play Console upload has been made.

Rebuild from the repository root: `node marketing/play-store-v4/compose.cjs`. The previous illustrated concept remains in `../play-store-v3/` for comparison.

I also tested an image-generation edit prompted to replace the cinematic scene with an Ironwood Forest combat-card composition using the real World, Combat Preview, and Companion captures as references. That edit invented parts of the interface, so the final graphic uses only the actual in-game assets and capture above. The generated edit was not used or saved into this pack.
