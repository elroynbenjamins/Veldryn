What was captured

These are actual React Native web components at a 432 CSS-pixel mobile layout, rendered at 2.5× scale. The game interface and artwork were not generated or repainted. Crops remove unrelated controls, empty space, and explanatory text. Separate screen sections are arranged into promotional layouts; these are not uninterrupted phone screenshots.

StoreCaptureReview supplies an isolated, memory-only sample profile. Guild members and messages are fictional. The dungeon ready check uses the same CoopLiveLobbyView as the live lobby, without mounting authentication, queue polling, or network actions. The pet collection opens its real Pets category. No saves, live guilds, chats, or queue tickets were changed.

Release checks

The seasonal screenshot is a staged Harvestwake preview; it does not establish that the event is live. Use it when the advertised seasonal feature is available in the release, and rotate it with the active festival. Confirm dungeon matchmaking is enabled in the release before using its image. Compare all captures with the final Android build because native layout and text rendering may differ from the mobile web capture.

Export and visual checks

All eight numbered exports are 1080 × 1920, 24-bit RGB PNGs without transparency. Headers occupy less than 20% of each image. Every crop is within source bounds and resized proportionally. Captures were visually checked for missing art, duplicated strips, cut-off controls, and readable text. The contact sheet is a preview, not a store screenshot.

Based on Google Play’s official preview-asset guidance, checked 1 October 2026. This pack uses genuine gameplay prominently and avoids rankings, download claims and install calls to action.

Edit or reproduce

Edit layouts.json, then run node marketing/play-store-v2/compose.cjs from the repository root. The compositor uses the configured Codex canvas/sharp runtime and installed Windows Georgia/Segoe UI fonts; no fonts are redistributed. Source crops and proportional placements are documented in manifest.json.

For fresh captures, run Expo with EXPO_PUBLIC_VISUAL_QA=1, EXPO_PUBLIC_VISUAL_QA_SCREEN=store, EXPO_PUBLIC_SERVER_GAMEPLAY=false, and EXPO_NO_DOTENV=1 on port 8104. Run node marketing/play-store-v2/serve.cjs, then open capture.html?screen=companions&offset=1010 through localhost:8113. The fixed wrapper avoids browser full-page stitching; adjacent bounded captures are joined at exact offsets. Networked production wrappers are not mounted.
